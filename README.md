# Sider · 原版 ChatGPT 侧栏

在当前网页旁打开原版 `chatgpt.com`，模型、会话、登录、附件和回答继续使用官方网站。扩展只在原版输入框旁加入网页引用工具，不需要 API Key。

## 安装 / 更新到 0.4.0

适用于 Chromium 145 及以上的 Tabbit、Chrome 和 Edge。加载构建目录：

```text
Q:\1Coding\Sider\dist
```

1. 在浏览器扩展管理页开启开发者模式，加载 `dist` 文件夹。已安装时点击 Sider 的“重新加载”，确认版本为 **0.4.0**。
2. 关闭旧侧栏，在要阅读的网页上点击 Sider 图标。
3. 如需登录 ChatGPT，点击侧栏右上角 `↗` 在普通标签页完成登录，再用 `↻` 刷新侧栏。

0.4.0 增加长正文自动转原生附件，并移除原来的发送字符上限。沿用现有权限，侧栏直接显示 ChatGPT 网页。

## 划词后直接提问

打开侧栏后，在网页正文中选中一个词或一段文字，输入框旁会自动显示当前划词。直接在原版 ChatGPT 输入框中写问题，按 Enter 或点击原版发送按钮，扩展会在发送前加入划词内容。

例如，网页上选中“Tabbit”，输入框中只写：

```text
这个词是什么意思？
```

默认发送内容为：

```text
网页划词：
Tabbit

这个词是什么意思？
```

每个标签页只保留当前划词，新划词替换旧划词。取消网页上的选择会清除预览；预览旁的 `×` 则取消本次引用。网页输入框、编辑器和密码框中的选择不会作为正文划词。

Shift+Enter 换行、输入法候选确认保持原版行为。扩展工具栏按钮用于选择引用和修改设置；发送始终由用户的 Enter 或 ChatGPT 发送按钮触发。

## 引用链接和正文

点击输入框旁的 **引用**，选择 **URL** 或 **正文**，工具栏会出现 `URL ×` 或 `正文 ×` 标签。写好问题后，发送时自动附加对应内容；点击标签上的 `×` 可取消。

选择引用时，问题草稿保持原样。日常输入框中不需要写变量，也不需要手动展开。引用菜单用于当前网页的链接和正文，不展示划词历史。

URL 引用提供网页地址。正文引用则提取当前已加载的主要内容，通过 Readability 和 Markdown 转换保留链接、列表、代码与表格。正文是在点击引用时采集的快照；需要更新时取消后重新引用。尚未加载、未展开的内容、iframe、图片和 Canvas 中的文字不会提取。

默认使用自动模式：展开后的正文引用超过 **10,000 字符**时，工具栏显示 `正文 · 附件 ×`，发送前将正文作为 UTF-8 TXT 文件添加到 ChatGPT 原生附件区。文件保留完整正文格式，并包含网页标题、来源 URL 和采集时间；问题、划词与 URL 仍留在消息中。文件在浏览器内存中生成，不需要下载到磁盘。

按 Enter 或点击原版发送后，扩展等待附件上传完成再发送。上传失败、准备期间修改问题、来源或会话变化会停止本次发送并保留问题；重复回车不会重复上传同一附件。取消正文引用会撤下扩展准备的附件；点击该文件原生的移除按钮也会取消正文引用。用户自行添加的其他附件保留。上传的正文文件带独立标识，附件说明使用实际文件名；同名用户附件会提示冲突，避免误用或误删。

## 自定义附加格式

点击输入框旁的 `⋯`，分别设置划词、URL、正文的附加文本格式，并选择放在问题前或问题后。变量只在这些设置格式中解析，问题本身保持普通文本。

| 变量 | 当前标签页中的含义 |
| --- | --- |
| `{{selection}}` | 当前划词 |
| `{{context}}` / `{{selection.context}}` | 划词附近的原文段落 |
| `{{url}}` | 网页 URL |
| `{{title}}` | 网页标题 |
| `{{content}}` / `{{page.content}}` | 已引用的网页正文 |
| `{{filename}}` | 仅用于附件引用说明，表示正文附件文件名 |

例如，将 URL 格式改成：

```text
网页url为：{{url}}
```

在 `https://example.com` 页面选择 URL 引用，最终附加文本为：

```text
网页url为：https://example.com/
```

正文发送方式可选 **自动 / 始终作为文本 / 始终作为附件**，自动模式的转换阈值可修改。正文格式在文本模式下添加到问题，在附件模式下写入文件；另一个“附件引用说明”负责添加到问题，默认使用 `{{filename}}` 引用文件。这个说明不支持 `{{content}}`，以免再次将整篇正文放回输入框。问题本身和捕获内容中的变量不会递归展开。

已移除 48,000 字符的发送拦截，旧字符上限不会转换成新的附件阈值；已有自定义格式和位置保留。格式中的变量缺少内容或使用未知变量时仍会保留问题并提示原因。引用采集仍有单项 100 万字符的保护，超出时明确拒绝而不截断；ChatGPT 自身的上传与发送结果由原版界面处理。

## 每个标签页各自使用

Sider 使用浏览器原生的标签页侧栏，并将侧栏绑定到打开它的标签页。网页一的划词、URL 和正文引用不会进入网页二；切回网页一会显示它自己的引用状态。每个标签页的侧栏使用各自的原版 ChatGPT 页面。

划词和引用状态保存在当前浏览器会话中；关闭标签页或导航到新页面会清除该页上下文，重启浏览器后不保留。格式、位置、正文发送方式和转换阈值保存在浏览器本地设置中，供各标签页共用。

新标签页先点击一次 Sider 图标，以取得该页的临时访问权。进入另一个网站后可能需要再次点击图标。遇到访问提示可使用 **允许当前网站**，通过浏览器原生提示授予该网站的持续访问权；这不需要新增扩展权限。

也可通过右键菜单引用划词、链接或正文，使用 `Alt+Shift+Q` 引用划词，或用 `Ctrl+Shift+Y` 打开当前标签页的侧栏。

## 连接与验证

侧栏等待 ChatGPT 的真实连接回执。点击侧栏右上角 `⋯` 可查看扩展版本、绑定的标签页、浏览器版本、兼容规则和增强层状态。如仍看到旧界面，请确认加载的是本项目的 `dist`，重新加载扩展并关闭旧侧栏。

ChatGPT 登录验证、网络限制或网站更新可能影响加载。无法在内嵌页面登录时，先在普通 ChatGPT 标签页完成登录，再刷新侧栏。增强工具仅安装在本扩展内嵌的 ChatGPT 中。

```sh
npm install
npm run check
```

`npm run check` 执行测试并构建 `dist/`。本地 `npm run dev` 页面只提供安装提示，完整侧栏需加载扩展。测试和隔离浏览器验证记录见 [docs/validation.md](docs/validation.md)；这些记录不代表用户的 Tabbit 已自动更新安装。

内嵌兼容使用 DNR 会话规则，限定于本扩展框架下的 `https://chatgpt.com/` 子框架。参考：[Chrome sidePanel 文档](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)、[Chrome activeTab 文档](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[Chrome 网站授权 API](https://developer.chrome.com/docs/extensions/reference/api/permissions)。
