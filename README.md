# Sider · 原版 AI 网页侧栏

在阅读网页时，直接在旁边的 AI 网页侧栏提问，并将选中文字、网页链接或正文作为问题的上下文。

Sider 是一个基于 Manifest V3 的浏览器扩展。侧栏展示原版 AI 网站，模型、会话和登录继续由原站提供；扩展负责采集当前网页内容，并在你发送问题时附加引用，无需 API Key。内置 ChatGPT、Gemini、Claude，也可以添加自定义网站。

## 功能

- **划词提问**：选中网页中的文字，写下问题，发送时自动加入当前划词。
- **引用链接与正文**：按需添加当前网页的 URL 或主要正文，正文转换为 Markdown，保留链接、列表、代码和表格。
- **长正文转附件**：默认超过 10,000 字符时生成 TXT 文件，等待原站上传完成后再发送问题；自定义网站检测到文本附件入口时，使用输入框中央的通用拖放。尚未检测到附件能力时，自动模式提示并改用完整文本。
- **全局 AI 网站设置**：统一选择 ChatGPT、Gemini、Claude 或自定义网站，重新打开或加载侧栏时生效。
- **点选发送按钮**：自动识别失败时，直接在页面选择原站发送按钮作为兜底，支持内置和自定义网站。
- **标签页独立引用**：各标签页分别保存自己的划词、链接和正文引用。
- **统一预设入口**：划词、网页链接和正文作为可编辑预置项，与自建预设一起管理、排序和恢复默认。
- **逐项默认勾选**：每条预设独立设置默认勾选、问题前／后位置及替换／追加／直接发送行为，临时选择按标签页保存。
- **逐项附件规则**：长划词、固定文本与正文都能按阈值转附件，每项独立生成 TXT 和附件说明，按顺序上传后发送一次。
- **正文快照**：点击正文标签查看完整 Markdown，复制、下载或手动刷新；发送前重新采集一次。
- **追加快照与草稿保护**：按位置保留已有草稿，重复追加只更新完整的系统追加块；用户编辑后的文字不会被覆盖。
- **完整配置备份**：在外层设置导出版本 3 JSON，接受旧版备份；导入先核对变更，再完整替换网站与预设。

## 安装

需要支持原生侧栏的 Chromium 浏览器，例如 Chrome、Edge 或 Tabbit。扩展声明的最低 Chromium 版本为 **145**；使用时需要能够访问并登录所选 AI 网站。

### 从源码构建

准备好 Node.js、npm 和 Git，然后执行：

```sh
git clone https://github.com/ChinaYong/Sider.git
cd Sider
npm ci
npm run build
```

也可以通过 GitHub 的 **Code → Download ZIP** 下载源码，解压后在项目目录中执行 `npm ci` 和 `npm run build`。

构建完成后：

1. 打开浏览器的扩展管理页面。Chrome 使用 `chrome://extensions/`，Edge 使用 `edge://extensions/`。
2. 开启 **开发者模式**，点击 **加载已解压的扩展**。
3. 选择构建生成的 **`dist` 文件夹**。
4. 打开要阅读的网页，点击工具栏中的 Sider 图标。

仓库保存源码，`dist/` 和 `Sider-*.zip` 是构建、打包产物，不随源码提交。浏览器会直接读取加载目录中的文件，安装后请保留该目录。

### 使用已构建的扩展包

如果你已取得 `Sider-<版本号>.zip` 扩展包，将其解压到固定目录，再按上面的步骤加载包含 `manifest.json` 的解压目录即可，无需安装 Node.js 或再次构建。

### 更新扩展

更新源码后重新执行 `npm ci` 和 `npm run build`；使用扩展包时，将新版本解压到原加载目录。随后在扩展管理页面点击 Sider 的 **重新加载**，关闭旧侧栏并重新打开。侧栏右上角的 `⋯` 可查看当前版本和连接信息。

## 使用

### 选择或添加 AI 网站

点击侧栏顶部的 **⚙ AI 网站设置**，选择网站并保存。网站选择全局共用；已打开的侧栏保留当前会话和草稿，点击更新提示或 `↻` 后使用新网站。各来源网页的引用状态仍独立保存。

添加自定义网站时填写名称和 HTTP(S) 地址，点击 **保存网站** 加入列表，再点击 **保存全局设置**。浏览器会按需请求所选网站的访问权限；拒绝授权或保存失败时，设置窗口保留编辑内容并显示原因。

自定义网站按页面结构自动识别输入框和发送控件：支持 textarea，以及普通、空属性和仅纯文本的 contenteditable 编辑器；优先使用输入框的消息标签、原生表单提交控件、发送按钮文字或标签，再尝试输入区附近的发送图标。规则不依赖网站名称或域名。识别失败或有多个同等匹配时，网页引用会显示未就绪；可在 **编辑网站 → 高级配置** 中填写输入框、发送控件和引用栏挂载位置的 CSS 选择器，并选择 Enter、Ctrl / ⌘ + Enter 或仅发送按钮。挂载位置表示将引用栏放在该元素之后。

发送按钮识别失败时，先在已加载的原站输入问题，使发送按钮出现，再打开 **AI 网站设置 → 配置网站 / 编辑网站 → 在页面点选发送按钮**。鼠标移到按钮上会显示边框，点击后自动记录选择器并返回设置；此次点击不会发送消息。按 Esc 或点击取消可退出，原草稿和配置保留。点击 **保存网站**、**保存全局设置** 后重新加载侧栏生效；之后仍按一次原站快捷键或点击一次发送按钮完成引用准备和发送。选择器优先于自动识别，按钮替换后重新查找；匹配缺失或不唯一时保留问题并显示原因。点击 **恢复自动识别发送按钮**、保存并重载即可清除此项配置。内置网站的名称和地址固定，原有适配继续使用。

自定义网站支持文本引用和按实际检测启用的 TXT 附件拖放。原站是否能在侧栏加载、登录、接受自动编辑或附件，需要实际检测；加载失败时仍可使用外层网站设置、重试及原站入口。原站标签页用于登录或正常聊天，网页引用增强在侧栏运行。

网页选中文字拖到自定义网站的输入框时，扩展按纯文本写入并保留已有问题，不触发发送；在已聚焦的 textarea 中会插入当前选区。文件、图片及链接拖放保留原站处理。输入框存在歧义、会话变化或原站拒绝完整写入时会停止并提示，避免写入错误会话或发送不完整内容。

首次就绪后，控件失效及恢复仍会同步到侧栏状态。如果检测到原站明确的 WebSocket 或实时连接失败提示，会显示原站文字、保留问题并阻止继续发送引用；提示消失后恢复，由你再次发送。这个检测不能确定失败原因或修复网站的内嵌连接限制。

正文附件共用原站文件操作解析和输入框拖放逻辑。通用拖放同时兼容直接读取文件列表、通过文件条目读取内容的上传组件，保留完整 UTF-8 正文。Gemini 优先拖放；自定义网站检测到明确的拖放区域且兼容层可用时，也优先拖放。其他情况沿用原站附件菜单或“上传文件”等操作，跟随该操作实际调用的文件输入，兼容多个隐藏输入和动态创建的输入，不弹出文件选择窗口。自定义网站只有接受 TXT 的文件输入且没有文件操作时，保留原来的拖放路线。每次准备只使用一条上传路线，不会在上传失败后换入口重复上传。

上传后仍需识别原站附件卡片、唯一的移除控件和明确完成状态，例如文本类型与文件大小；实际发送前再确认原站发送控件可用。追加或空草稿直发先确认附件就绪，再写入说明，避免等待尚未有文字时禁用的发送按钮。仅出现文件名或上传提示消失不代表完成；无法确认、原站报错或超时时停止发送并保留问题和预设，不会在已尝试上传后自动改发文本。取消时只清理扩展自己的附件；清理无法确认时，先在原站附件区域手动移除后再重试。尚未检测到附件入口时，自动模式提示并使用完整文本；“始终附件”模式停止发送。可在 **预设 → 编辑 → 高级** 中选择“始终文本”，或调整正文默认 10,000 字符的阈值。

通用规则不依赖网站域名，也不能保证所有网站接受模拟拖放或提供可识别的上传状态。真实 DeepSeek 普通标签页已验证约 28 KB TXT 的通用拖放、带小数文件大小的完成检测与自有附件清理，没有发送聊天；侧栏完整引用发送由本地测试网页验证，真实内嵌会话发送仍需现场确认。

Gemini 的通用拖放路线无需打开“上传和工具”菜单。兼容层不可用时，在上传前选择原来的菜单路线；动作识别支持无障碍标签、关联标签及可见文字，窄屏中的“文件”或“Files”短名称只在已绑定的附件菜单内生效。附件预览中截短的名称以原生提示里的完整文件名核对，默认悬停才显示的移除按钮不会阻止完成检测。仍会等待原站上传进度结束，实际发送前确认发送控件可用；附件外层的进度和错误也会阻止发送，原站报错时保留问题。

Gemini 发送后的 TXT 附件预览可能显示“无法预览”。真实临时对话对照中，同内容的原生本地上传与扩展上传均出现该提示，而 Gemini 均准确读出了附件末尾内容；点击预览与模型读取正文属于不同功能，不能仅凭这个提示判定正文上传失败。

ChatGPT、Gemini、Claude 的增强流程已用本地测试网页验证。Claude 侧栏可用来自用户反馈，自动附件的真实网站回归仍需补充。Gemini 普通标签页在 420px、320px 宽度下已验证约 116 KB TXT 的通用拖放、完整内容、完成检测和自有清理；本轮的新功能没有向真实账号发送测试消息。原站服务或账号上传失败仍可能导致附件无法完成。详见开发验证记录。

### 划词提问

1. 在要阅读的网页上点击 Sider 图标，打开侧栏并取得当前网页的临时访问权。
2. 在网页正文中选中一个词或一段文字，输入框旁会显示当前划词。
3. 在原站输入框中写问题，使用原站发送快捷键或点击发送按钮。

例如，选中“Tabbit”并输入“这个词是什么意思？”，默认发送内容为：

```text
网页划词：
Tabbit

这个词是什么意思？
```

新划词会替换旧划词；取消网页上的选择会清除预览。标签旁的 `×` 取消当前预设的附加，后台刷新不会重新开启；新划词只更新内容，手动勾选或取消持续生效到刷新或导航。输入框、编辑器和密码框中的选择不会作为正文划词。

选择引用时，问题草稿保持原样；内容在发送前加入。Shift+Enter 换行与输入法候选确认保持原版行为，发送由你的原站发送快捷键或发送按钮触发。

### 预设与发送时引用

输入框旁只有一个 **预设** 入口。“划词”“网页链接”“网页正文”为预置项，可编辑名称、内容和全部设置，并在编辑页恢复默认；预置项不能删除。自建预设可删除。使用拖动手柄或上下箭头调整顺序，同一位置按列表顺序组合。拖动支持列表边缘滚动，Esc 或指针取消会恢复原顺序；保存冲突会提示核对。禁用箭头使用普通光标。

每条预设独立设置 **位置（问题前／后）**、**默认勾选** 和 **点击行为**。列表旁的勾选框名为“发送时引用”，只决定发送时是否带上该项，不修改草稿；点击名称执行其配置行为，发送方式另行控制文本或附件。

| 点击行为 | 结果 |
| --- | --- |
| 替换 | 替换全部草稿文字，清理旧预设生成的附件及快照，保留用户自行上传的文件；不发送 |
| 追加 | 使用当时变量快照，按问题前／后保留完整草稿；需要附件时先上传，再追加说明，不发送 |
| 直接发送 | 执行追加，与现有草稿和其它勾选项一起准备；允许草稿为空，最终消息不能为空；所有附件就绪后发送一次 |

新建项默认为“追加”“问题后”“始终文本”，默认勾选关闭。默认勾选只控制预选，不会自动追加或发送。初始预置项只开启划词默认勾选。保存默认值的修改立即应用于当前网页，其他已打开网页保留临时选择。每次通过 Enter、原站发送按钮或预设直接发送消息后，自动取消当前网页全部预设的勾选，包括等待划词的项；发送准备失败时保留勾选。取消后，后台检查或重开侧栏不会恢复；刷新或导航后重新应用默认值。

依赖划词的勾选项在无划词时保持勾选、显示 **等待划词** 并跳过，不妨碍普通提问。手动勾选与默认勾选使用相同规则；新划词不重置选择。显式执行缺少划词，或预设需要的其它变量缺失时，会指出预设及变量并停止操作。

已附加项或追加快照以可取消标签显示。点击标签查看完整展开内容、字符数及预计文本／附件方式。正文项还提供 **查看正文快照**，可复制完整正文、下载 Markdown 或刷新一次；打开、关闭和普通后台刷新不会重新采集。准备发送期间不可手动刷新。

重复追加同项只更新仍完整匹配的系统追加块；用户改过该块时保留文字并提示。清空草稿、成功发送或切换会话会清除块记录。同一预设在一次发送中只计入一次，显式执行或已追加快照优先于默认勾选；不同预设引用相同正文仍各自保留。追加快照不会随正文、预设设置或后台刷新自动改写。

替换先校验、上传新材料，再清理旧预设文件并写入新草稿。新材料准备失败时保留旧草稿和旧文件；旧文件部分清理失败则停止替换，保留草稿，并将已缺失项标为可重试。原生附件清理不能保证完全回滚。替换和追加不改变“发送时引用”的勾选，直接发送在交给原站发送后清空勾选。

### 变量与正文采集

预设内容支持文本和变量，日常草稿中的花括号保持原样。预设实际使用的变量决定是否需要正文，与名称及预置身份无关。

| 变量 | 含义 |
| --- | --- |
| `{{selection}}` | 当前划词 |
| `{{context}}` / `{{selection.context}}` | 划词附近的原文段落 |
| `{{url}}` | 当前网页 URL |
| `{{title}}` | 当前网页标题 |
| `{{content}}` / `{{page.content}}` | 按需采集的网页正文 |
| `{{template.name}}` | 当前预设名称 |
| `{{filename}}` | 实际上传文件名，仅用于附件说明 |
| `{{url.host}}` | 来源网址主机名 |
| `{{date}}` / `{{time}}` / `{{datetime}}` | 本机时区，格式为 YYYY-MM-DD、HH:mm:ss、YYYY-MM-DD HH:mm:ss |
| `{{page.author}}` / `{{page.publishedAt}}` / `{{page.capturedAt}}` | 正文快照记录的作者、发布时间、采集时间；页面未提供时会提示缺失 |

编辑页面的 **查看全部变量** 提供条件、例子、采集时点和复制按钮。URL、标题无需开启相应预置项；正文及元信息按需采集。一条操作中的预设共享同一份正文及时间，变量只展开一次，网页原文中的花括号不会再次解析。来源、草稿、设置或会话在准备期间改变会取消操作并保留可恢复草稿。

默认正文或含正文变量的附加项启用时先采集一次；每次发送前再刷新一次，后续校验和上传使用同一快照。失败会停止发送，不使用旧正文。正文只包含已加载的主要内容，保留已存在的折叠说明、链接、列表、代码、表格及提取说明；不采集隐藏元素、输入框、编辑器以及 iframe、图片、Canvas 中的文字。明确忙碌或只有加载占位内容时报告未就绪，短小真实正文仍可使用。

### 每项附件设置

在内容编辑框中使用一对 `<attachment>…</attachment>` 标记需要转为附件的材料。**设为附件区域** 按钮会包裹选中文字；没有选区时插入空标记并定位光标。每条预设只支持一个非空区域，可以同时放入多个变量和固定文字：

```text
总结网页内容。

网页内容：
<attachment>
{{content}}
</attachment>

请用中文回答。
```

未转附件时去掉标记、原位展开全文；转附件后，“总结网页内容”和“请用中文回答”留在问题中，正文进入 TXT。预览分别展示最终提示词、附件材料及计数字符数。未闭合、嵌套、多个或空区域不能保存；`\<attachment>`、`\</attachment>` 表示字面标记。标记在变量展开前解析，网页原文中的同名标记保持原样。

在 **编辑预设 → 高级** 中选择 **始终文本／超出阈值转附件／始终附件**。文本方式折叠附件配置。有附件区域时只计算该区域展开后的字符数；没有标记则计算整条预设。严格超过阈值才转附件，不计其它预设、草稿和统一资料边界说明；正文预置项默认自动转换，阈值为 **10,000 字符**。长划词、上下文和固定文本也适用，单项与最终消息沿用 100 万字符上限，不静默截断。

每条预设最多生成一个独立 UTF-8 TXT。有标记时只包含区域材料，区域外指令保留在问题中，原位置替换成附件说明；无标记时包含整条展开内容。含正文的预设继续携带来源、采集范围和资料边界；文件名结合预设名称并带唯一所有权标记。附件说明默认是 `预设“{{template.name}}”的内容见附件《{{filename}}》。`，可以逐项覆盖；说明不允许正文变量，防止把全文再次写进消息。“始终文本”保留但不校验未使用的附件说明。

附件依次上传，全部确认就绪后才发送一次。任意必需附件失败会停止发送；已尝试上传后不自动回退。没有附件能力时，自动方式提示并改用完整文本，强制附件方式停止。准备其它预设不会清理已追加快照的附件。只移除扩展自己的文件，用户自行添加的附件保留。

原生附件被手动移除后，对应标签标为缺失，后续发送停止。点击标签可 **重试附件** 或 **移除该项**；追加快照重试使用原始内容和时间。移除已编辑的追加块时保留用户文字，并提示检查附件说明。

Claude 和自定义网站短暂替换发送控件时，扩展等待最多 500 毫秒；发送快捷键等待真实按钮，失败则保留草稿。配置错误和多个匹配立即提示。

### 配置导入／导出

在外层 **⚙ AI 网站设置 → 配置导入／导出** 导出版本 3 JSON；即使 AI 网站加载失败，该入口仍可用。备份覆盖完整预设列表、位置／行为／默认勾选／附件设置、选用网站、自定义网站、控件选择器及发送快捷键、Gemini 界面／模型／思考，以及自动划词网站列表。

继续接受版本 1、2，使用与首次启动相同的迁移逻辑：原引用配置映射为三条预置项，正文发送方式、阈值和附件说明保留；旧快捷预设保留内容和直接发送选择，其它项迁移为问题后追加。版本 2 的“附加／填入”行为转为“追加”，直接发送保留；旧内容中的字面附件标记转义后保留，不自动猜测指令边界。迁移校验后一次写入 `sider.templates.v3`，旧配置键保留用于恢复，新存储是运行时配置来源。

导入先校验整个文件，再显示网站、预设和附件设置的变更；点击 **按预览完整替换配置** 才执行。旧网站和自建预设不会合并，三条预置身份必须保留。缺失必需字段、错误版本、非法变量／网址／选择器、重复 ID、授权拒绝或存储失败都会保留已有配置。预览后配置变化时需重新选择文件核对。

权限在使用网站时单独授权，导入只对所选 AI 网站按需申请一次授权。登录、聊天、正文、划词、草稿、诊断和连接标识不写入备份；浏览器管理的扩展快捷键不随文件转移。已打开侧栏保留会话和问题，网站变更通过现有重新加载入口生效；导入的默认勾选用于后续初始化，不重置其他网页的临时选择。

### 快捷操作

| 操作 | 默认快捷键 |
| --- | --- |
| 打开当前标签页的侧栏 | `Ctrl+Shift+Y` |
| 引用当前划词 | `Alt+Shift+Q` |

也可以通过网页右键菜单引用划词、链接或正文。右键菜单、划词快捷键和网页划词按钮始终启用对应预置项的“发送时引用”，不执行其“替换／追加／直接发送”点击行为。快捷键可在浏览器的扩展快捷键设置中调整。

## 数据与网站权限

- 网页内容在浏览器内采集，选中的引用随你的问题或附件提交到当前 AI 网站。
- 划词和引用状态保存在当前浏览器会话中，各标签页独立；关闭标签页、导航到新页面或重启浏览器后会清除。
- 格式、位置、正文发送方式和转换阈值保存在浏览器本地，供各标签页共用。
- AI 网站选择和自定义配置独立保存在浏览器本地。新增网站按需授权，脚本和嵌入兼容规则仅针对已登记的网站；后台校验侧栏对应的网站与来源标签页。
- 点击扩展图标可取得当前网页的临时访问权。进入另一个网站后，可能需要再次点击图标；**允许当前网站**可通过浏览器提示授予该网站的持续访问权。

## 常见问题

**侧栏无法登录或加载 AI 网站**

打开侧栏后，原站页面会随网站加载逐步显示，不等待网页引用连接完成。加载进度显示在顶部状态栏；若尚未确认连接，上方会提供重新连接和登录入口，已显示的页面仍可继续操作。

点击侧栏右上角的 `↗`，在同一浏览器的普通原站标签页完成登录，再点击 `↻` 刷新侧栏。登录验证、网络限制和网站更新可能影响加载；右上角 `⋯` 提供可复制的连接信息，`⚙` 始终可用于切换网站或修正配置。

如果原站已打开，但状态栏提示 **网页引用未就绪**，可继续正常聊天。需要附加网页引用时，检查网站配置或点击右上角 `↻` 重新连接；连接信息中会显示具体原因。网站授权失败的原因会显示在授权窗口内，可直接重试。

**网页划词或正文没有出现**

先在当前网页点击一次 Sider 图标，或按提示允许当前网站。正文需已加载并能从页面中提取；已登记的 AI 网站页面和浏览器内部页面不支持作为网页引用来源。单项引用超过 100 万字符时会提示缩小范围，不会静默截断。

**更新后仍显示旧界面**

确认加载的是更新后的构建目录，在扩展管理页面重新加载 Sider，再关闭旧侧栏并重新打开。

## 开发

| 命令 | 作用 |
| --- | --- |
| `npm ci` | 按锁定版本安装依赖 |
| `npm run build` | 构建浏览器可加载的 `dist/` |
| `npm test` | 运行自动化测试 |
| `npm run test:browser` | 构建后运行隔离浏览器回归，安装方式见 [浏览器测试说明](docs/browser-tests.md) |
| `npm run check` | 运行测试并构建 |
| `npm run dev` | 启动本地安装提示与示例文章页面 |

完整 AI 网页侧栏需要在浏览器中加载扩展。本地开发页面用于辅助调试，验证范围和记录见 [docs/validation.md](docs/validation.md)。

| 目录或文件 | 用途 |
| --- | --- |
| `src/` | 后台、侧栏、网页采集、网站适配与公共增强层源码 |
| `manifest.json` | 扩展配置、权限和版本 |
| `scripts/` | 构建与本地开发脚本 |
| `tests/` | 自动化测试 |
| `docs/` | 验证记录 |
| `dist/` | 由源码生成的可加载扩展 |
| `Sider-*.zip` | 对应版本构建产物的压缩包 |

`npm run build` 只生成 `dist/`，不会自动生成 ZIP。分发扩展时，将 `dist/` 内的文件压缩到 ZIP 根目录，使解压后可直接找到 `manifest.json`。
