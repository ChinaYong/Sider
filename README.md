# Sider · 原版 AI 网页侧栏

在阅读网页时，直接在旁边的 AI 网页侧栏提问，并将选中文字、网页链接或正文作为问题的上下文。

Sider 是一个基于 Manifest V3 的浏览器扩展。侧栏展示原版 AI 网站，模型、会话和登录继续由原站提供；扩展负责采集当前网页内容，并在你发送问题时附加引用，无需 API Key。内置 ChatGPT、Gemini、Claude，也可以添加自定义网站。

## 功能

- **划词提问**：选中网页中的文字，写下问题，发送时自动加入当前划词。
- **引用链接与正文**：按需添加当前网页的 URL 或主要正文，正文转换为 Markdown，保留链接、列表、代码和表格。
- **长正文转附件**：默认超过 10,000 字符时生成 TXT 文件，等待原站上传完成后再发送问题；自定义网站检测到文本附件入口时，使用输入框中央的通用拖放。尚未检测到附件能力时，自动模式提示并改用完整文本。
- **全局 AI 网站设置**：统一选择 ChatGPT、Gemini、Claude 或自定义网站，重新打开或加载侧栏时生效。
- **点选发送按钮**：自动识别失败时，直接在页面选择原站发送按钮作为兜底，支持内置和自定义网站。
- **标签页独立引用**：各标签页分别保存自己的划词、链接和正文引用。
- **默认附加引用**：分别选择默认附加划词、网页链接和正文，打开侧栏时自动准备，当前网页仍可临时取消。
- **自定义引用格式**：分别设置引用内容、放置位置、正文发送方式和附件转换阈值。

## 安装

需要支持原生侧栏的 Chromium 浏览器，例如 Chrome、Edge 或 Tabbit。扩展声明的最低 Chromium 版本为 **145**；使用时需要能够访问并登录所选 AI 网站。

### 从源码构建

准备好 Node.js、npm 和 Git，然后执行：

```sh
git clone https://github.com/ChinaYong/Sider.git
cd Sider
npm ci
npm run build
```

也可以通过 GitHub 的 **Code → Download ZIP** 下载源码，解压后在项目目录中执行 `npm ci` 和 `npm run build`。

构建完成后：

1. 打开浏览器的扩展管理页面。Chrome 使用 `chrome://extensions/`，Edge 使用 `edge://extensions/`。
2. 开启 **开发者模式**，点击 **加载已解压的扩展**。
3. 选择构建生成的 **`dist` 文件夹**。
4. 打开要阅读的网页，点击工具栏中的 Sider 图标。

仓库保存源码，`dist/` 和 `Sider-*.zip` 是构建、打包产物，不随源码提交。浏览器会直接读取加载目录中的文件，安装后请保留该目录。

### 使用已构建的扩展包

如果你已取得 `Sider-<版本号>.zip` 扩展包，将其解压到固定目录，再按上面的步骤加载包含 `manifest.json` 的解压目录即可，无需安装 Node.js 或再次构建。

### 更新扩展

更新源码后重新执行 `npm ci` 和 `npm run build`；使用扩展包时，将新版本解压到原加载目录。随后在扩展管理页面点击 Sider 的 **重新加载**，关闭旧侧栏并重新打开。侧栏右上角的 `⋯` 可查看当前版本和连接信息。

## 使用

### 选择或添加 AI 网站

点击侧栏顶部的 **⚙ AI 网站设置**，选择网站并保存。网站选择全局共用；已打开的侧栏保留当前会话和草稿，点击更新提示或 `↻` 后使用新网站。各来源网页的引用状态仍独立保存。

添加自定义网站时填写名称和 HTTP(S) 地址，点击 **保存网站** 加入列表，再点击 **保存全局设置**。浏览器会按需请求所选网站的访问权限；拒绝授权或保存失败时，设置窗口保留编辑内容并显示原因。

自定义网站按页面结构自动识别输入框和发送控件：支持 textarea，以及普通、空属性和仅纯文本的 contenteditable 编辑器；优先使用输入框的消息标签、原生表单提交控件、发送按钮文字或标签，再尝试输入区附近的发送图标。规则不依赖网站名称或域名。识别失败或有多个同等匹配时，网页引用会显示未就绪；可在 **编辑网站 → 高级配置** 中填写输入框、发送控件和引用栏挂载位置的 CSS 选择器，并选择 Enter、Ctrl / ⌘ + Enter 或仅发送按钮。挂载位置表示将引用栏放在该元素之后。

发送按钮识别失败时，先在已加载的原站输入问题，使发送按钮出现，再打开 **AI 网站设置 → 配置网站 / 编辑网站 → 在页面点选发送按钮**。鼠标移到按钮上会显示边框，点击后自动记录选择器并返回设置；此次点击不会发送消息。按 Esc 或点击取消可退出，原草稿和配置保留。点击 **保存网站**、**保存全局设置** 后重新加载侧栏生效；之后仍按一次原站快捷键或点击一次发送按钮完成引用准备和发送。选择器优先于自动识别，按钮替换后重新查找；匹配缺失或不唯一时保留问题并显示原因。点击 **恢复自动识别发送按钮**、保存并重载即可清除此项配置。内置网站的名称和地址固定，原有适配继续使用。

自定义网站支持文本引用和按实际检测启用的 TXT 附件拖放。原站是否能在侧栏加载、登录、接受自动编辑或附件，需要实际检测；加载失败时仍可使用外层网站设置、重试及原站入口。原站标签页用于登录或正常聊天，网页引用增强在侧栏运行。

网页选中文字拖到自定义网站的输入框时，扩展按纯文本写入并保留已有问题，不触发发送；在已聚焦的 textarea 中会插入当前选区。文件、图片及链接拖放保留原站处理。输入框存在歧义、会话变化或原站拒绝完整写入时会停止并提示，避免写入错误会话或发送不完整内容。

首次就绪后，控件失效及恢复仍会同步到侧栏状态。如果检测到原站明确的 WebSocket 或实时连接失败提示，会显示原站文字、保留问题并阻止继续发送引用；提示消失后恢复，由你再次发送。这个检测不能确定失败原因或修复网站的内嵌连接限制。Grok 在侧栏发送后的实际连接失败仍未定位，未验证为已修复。

正文附件使用原站的文件操作或拖放入口。Gemini 和自定义网站共用上传入口识别：优先查找输入区域的附件菜单或“上传文件”等操作，跟随该操作实际调用的文件输入，兼容多个隐藏输入和动态创建的输入，不弹出文件选择窗口。自定义网站没有这类操作时，若附近存在接受 TXT 的文件输入或明确的拖放区域，则在输入框中央拖放完整 UTF-8 TXT 一次。每次准备只使用一条上传路线，不会在上传失败后换入口重复上传。

上传后仍需识别原站附件卡片、唯一的移除控件和明确完成状态，例如文本类型与文件大小，同时确认原站发送控件可用。仅出现文件名或上传提示消失不代表完成；无法确认、原站报错或超时时停止发送并保留问题和引用，不会在已尝试上传后自动改发正文文本。取消时只清理本次生成的附件；清理无法确认时，先在原站附件区域手动移除后再重试。尚未检测到附件入口时，自动模式仍提示并使用完整正文文本；“始终作为附件”模式停止发送。可在引用设置中选择“始终作为文本”，或调整默认 10,000 字符的附件阈值。

通用规则不依赖网站域名，也不能保证所有网站接受模拟拖放或提供可识别的上传状态。真实 DeepSeek 普通标签页已验证约 26 KB TXT 的通用拖放、带小数文件大小的完成检测与自有附件清理，没有发送聊天；侧栏完整引用发送由本地测试网页验证，真实内嵌会话发送仍需现场确认。

Gemini 通过通用逻辑打开原站“上传和工具”菜单，再追踪“上传文件”动作实际调用的文件输入。动作识别支持无障碍标签、关联标签及可见文字，不要求按钮位于特定组件；窄屏菜单中简写为“文件”或“Files”的按钮也能识别，这类简短名称只在已绑定的附件菜单内生效。菜单渲染期间暂时出现多个输入时，会在原有超时内等待文件操作就绪。附件预览中截短的名称以原生提示里的完整文件名核对，移除按钮默认悬停才显示也不会阻止完成检测。仍会等待原站上传进度结束及发送控件可用，原站错误则停止发送并保留问题。

ChatGPT、Gemini、Claude 的增强流程已用本地测试网页验证。Gemini 普通标签页已验证约 26 KB TXT 的原生入口上传、完成检测和自有清理；真实侧栏会话发送及 Claude 自动附件仍待现场验证。原站服务或账号上传失败仍可能导致附件无法完成。详见开发验证记录。

### 划词提问

1. 在要阅读的网页上点击 Sider 图标，打开侧栏并取得当前网页的临时访问权。
2. 在网页正文中选中一个词或一段文字，输入框旁会显示当前划词。
3. 在原站输入框中写问题，使用原站发送快捷键或点击发送按钮。

例如，选中“Tabbit”并输入“这个词是什么意思？”，默认发送内容为：

```text
网页划词：
Tabbit

这个词是什么意思？
```

新划词会替换旧划词；取消网页上的选择会清除预览，预览旁的 `×` 会清除当前划词引用，同时取消网页上的文字选择。重新划词后按默认设置附加。输入框、编辑器和密码框中的选择不会作为正文划词。

选择引用时，问题草稿保持原样；内容在发送前加入。Shift+Enter 换行与输入法候选确认保持原版行为，发送由你的原站发送快捷键或发送按钮触发。

### 引用链接与正文

点击输入框旁的 **引用**，选择 **URL** 或 **正文**。已选择的引用以标签显示，点击标签上的 `×` 可取消。

划词是否自动附加由设置中的 **默认附加 → 划词** 控制。即使关闭默认划词，右键“用 Sider 引用划词”、快捷键或网页划词按钮仍能主动引用当前选区。

开启正文引用或默认正文时会先采集一份正文，每次发送前再重新提取当前已加载的最新内容，并等待提取完成。同一次发送只更新一次正文，后续检查和附件上传使用这一份结果；后台刷新不会反复提取。提取失败会停止发送并保留问题，不会退回旧正文。扩展只提取当前已加载的主要内容，已存在于页面中的折叠说明会保留并标注；尚未加载的内容，以及 iframe、图片和 Canvas 中的文字不在采集范围内。隐藏元素、输入框和可编辑区域仍不会被采集。

普通正文文本与 TXT 附件使用相同的资料封装，包含标题、来源 URL、采集时间、采集范围和实际提取说明；页面提供的作者和发布时间也会保留。网页原文与用户问题明确分开。正文识别遗漏主区域中的段落、代码、表格或注释时，会改用主区域并说明原因；复杂表格保留单元格链接与合并关系，代码保留缩进。

默认自动模式下，按设置格式展开的正文超过 **10,000 字符**时，会生成 UTF-8 TXT 附件，此阈值不计统一附加的来源信息与资料边界。问题、划词与 URL 仍留在消息中。文件在浏览器内存中生成，无需下载到磁盘。

自动附件按网站能力启用；尚未支持自动上传时，自动模式显示 **正文 · 文本**，提示后改为附加全文。“始终作为附件”模式则保留问题并停止发送，提示改用文本或切换网站。扩展不会截断正文，也不会把上传超时当作上传成功。

发送时会等待附件上传完成，准备和取消提示持续显示，重复发送不会再次上传。上传失败时显示可识别的原站原因或超时提示，停止本次发送并保留问题和引用；已尝试上传后不会自动改发正文文本，由你重试或切换发送方式。准备期间问题、引用、设置、来源网页或会话发生变化，也会停止本次发送并保留草稿。取消正文引用会移除扩展生成的附件，用户自行添加的附件会保留；无法确认清理时会说明原因，确认清理后才能重新发送。

Claude 和自定义网站在同一输入框内短暂替换发送控件时，扩展等待最多 500 毫秒再显示控件缺失提示；这期间按发送快捷键会等待真实按钮，等待失败则保留草稿。配置错误和多个匹配仍立即提示。

### 默认附加引用

点击输入框旁的 `⋯`，在设置顶部的 **默认附加** 中分别勾选 **划词 / 网页链接 / 网页正文**，然后保存。初始设置只开启划词，链接和正文关闭。

修改过的默认选项会立即应用到当前网页，后续打开的网页也会沿用。其他已打开网页保留当前选择；仅修改引用格式不会重置手动选择。新划词按默认开关决定是否加入，没有划词时正常提问。

引用标签上的 `×` 和“引用”菜单用于临时取消，后台刷新、发送前检查和重开侧栏不会重新开启已取消的引用。刷新或导航到新网页后重新应用默认值。

如果正文无法采集，会显示 **正文 · 未就绪**，并提供 **重试正文** 或网站授权入口。处理前保留问题并阻止发送，避免遗漏已要求附加的正文；也可取消正文后继续提问。普通后台刷新不会反复重试失败的正文采集。

### 自定义格式

点击输入框旁的 `⋯`，分别设置划词、URL 和正文的附加格式，并选择放在问题前或问题后。变量只在设置格式中解析，日常提问直接输入普通文本即可。

| 变量 | 含义 |
| --- | --- |
| `{{selection}}` | 当前划词 |
| `{{context}}` / `{{selection.context}}` | 划词附近的原文段落 |
| `{{url}}` | 当前网页 URL |
| `{{title}}` | 当前网页标题 |
| `{{content}}` / `{{page.content}}` | 已引用的网页正文 |
| `{{filename}}` | 正文附件的实际文件名，仅用于附件引用说明 |

例如，将 URL 格式设置为 `请参考这个页面：{{url}}`，发送时会替换为当前网页地址。格式引用的内容需要已采集；未知变量或缺少内容时会提示原因并保留问题。

保存设置时会检查空格式、未知变量和附件说明中不支持的正文变量，错误显示在对应字段旁，未保存的修改会保留。支持的变量可提前设置，发送时再检查是否已取得所需引用。“始终作为文本”不会校验未使用的附件说明；切换自动或附件模式后再检查。保存失败时可直接在设置窗口查看原因并重试。

正文发送方式可选 **自动 / 始终作为文本 / 始终作为附件**。自动模式的转换阈值可修改；附件模式下，正文格式写入文件，**附件引用说明**添加到问题中。使用 `{{filename}}` 引用附件，附件说明不支持 `{{content}}` 或 `{{page.content}}`。

### 快捷操作

| 操作 | 默认快捷键 |
| --- | --- |
| 打开当前标签页的侧栏 | `Ctrl+Shift+Y` |
| 引用当前划词 | `Alt+Shift+Q` |

也可以通过网页右键菜单引用划词、链接或正文。快捷键可在浏览器的扩展快捷键设置中调整。

## 数据与网站权限

- 网页内容在浏览器内采集，选中的引用随你的问题或附件提交到当前 AI 网站。
- 划词和引用状态保存在当前浏览器会话中，各标签页独立；关闭标签页、导航到新页面或重启浏览器后会清除。
- 格式、位置、正文发送方式和转换阈值保存在浏览器本地，供各标签页共用。
- AI 网站选择和自定义配置独立保存在浏览器本地。新增网站按需授权，脚本和嵌入兼容规则仅针对已登记的网站；后台校验侧栏对应的网站与来源标签页。
- 点击扩展图标可取得当前网页的临时访问权。进入另一个网站后，可能需要再次点击图标；**允许当前网站**可通过浏览器提示授予该网站的持续访问权。

## 常见问题

**侧栏无法登录或加载 AI 网站**

打开侧栏后，原站页面会随网站加载逐步显示，不等待网页引用连接完成。加载进度显示在顶部状态栏；若尚未确认连接，上方会提供重新连接和登录入口，已显示的页面仍可继续操作。

点击侧栏右上角的 `↗`，在同一浏览器的普通原站标签页完成登录，再点击 `↻` 刷新侧栏。登录验证、网络限制和网站更新可能影响加载；右上角 `⋯` 提供可复制的连接信息，`⚙` 始终可用于切换网站或修正配置。

如果原站已打开，但状态栏提示 **网页引用未就绪**，可继续正常聊天。需要附加网页引用时，检查网站配置或点击右上角 `↻` 重新连接；连接信息中会显示具体原因。网站授权失败的原因会显示在授权窗口内，可直接重试。

**网页划词或正文没有出现**

先在当前网页点击一次 Sider 图标，或按提示允许当前网站。正文需已加载并能从页面中提取；已登记的 AI 网站页面和浏览器内部页面不支持作为网页引用来源。单项引用超过 100 万字符时会提示缩小范围，不会静默截断。

**更新后仍显示旧界面**

确认加载的是更新后的构建目录，在扩展管理页面重新加载 Sider，再关闭旧侧栏并重新打开。

## 开发

| 命令 | 作用 |
| --- | --- |
| `npm ci` | 按锁定版本安装依赖 |
| `npm run build` | 构建浏览器可加载的 `dist/` |
| `npm test` | 运行自动化测试 |
| `npm run check` | 运行测试并构建 |
| `npm run dev` | 启动本地安装提示与示例文章页面 |

完整 AI 网页侧栏需要在浏览器中加载扩展。本地开发页面用于辅助调试，验证范围和记录见 [docs/validation.md](docs/validation.md)。

| 目录或文件 | 用途 |
| --- | --- |
| `src/` | 后台、侧栏、网页采集、网站适配与公共增强层源码 |
| `manifest.json` | 扩展配置、权限和版本 |
| `scripts/` | 构建与本地开发脚本 |
| `tests/` | 自动化测试 |
| `docs/` | 验证记录 |
| `dist/` | 由源码生成的可加载扩展 |
| `Sider-*.zip` | 对应版本构建产物的压缩包 |

`npm run build` 只生成 `dist/`，不会自动生成 ZIP。分发扩展时，将 `dist/` 内的文件压缩到 ZIP 根目录，使解压后可直接找到 `manifest.json`。
