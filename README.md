# Sider

**一边读网页，一边和你熟悉的 AI 聊天。**

Sider 是一个 Chromium 浏览器扩展，把 ChatGPT、Gemini、Claude 等原版 AI 网站放进浏览器侧栏。文章留在眼前，对话就在旁边：遇到不懂的地方可以划词提问，需要整理全文时可以引用正文，常用的提示词也能保存下来反复使用。

**使用已有的 AI 网站账号，无需 API Key。** 模型选择、历史对话和文件上传继续由原站提供，Sider 负责把网页里的材料带进你的提问。

## Sider 能帮你做什么

### 把熟悉的 AI 留在手边

读技术文档、查资料或看外文文章时，打开侧栏就能接着聊。你使用的仍是 AI 网站自己的界面，可以选择模型、打开历史对话、上传文件，同时继续浏览当前网页。

内置 **ChatGPT、Gemini、Claude**，也支持添加自定义 AI 网站。Gemini 还可以设置普通／Spark 界面，以及默认模型和思考等级；实际可用功能取决于原站和你的账号。

### 划一段来问，也可以让 AI 读整篇

- **划词**：选中一个术语、一段原文或一段代码，勾选“划词”，再问“这是什么意思？”“帮我翻译一下”或“这里为什么会报错？”。
- **网页链接**：随问题附上来源地址，方便说明正在讨论哪一页。
- **网页正文**：提取页面已加载的主要内容，整理成 Markdown，尽量保留标题、链接、列表、代码和表格。可以先查看正文快照，再复制或下载。

连续阅读时，可以把划词设为 **“总是选中 ∞”**，之后的提问会持续带上当前划词，发送后也保留这一设置。没有划词时，普通问题仍可照常发送。

长文也不用手动拆开粘贴：正文默认超过 **10,000 字符**时会在支持上传的网站转成 TXT 附件。每条预设都能单独设置发送方式和阈值，还可以只把材料部分放进附件，让提问和指令留在消息里。

### 把常用问法变成自己的预设

“翻译这段话”“提炼文章观点”“解释这段代码”都可以保存成预设。固定指令里能插入划词、附近原文、网页标题、链接、正文等变量，每次使用时自动填入对应材料。

例如，保存一条“解释术语”：

```text
请结合上下文，解释“{{selection}}”的含义，并举一个容易理解的例子。

上下文：
{{selection.context}}
```

预设有两种常用方式：**勾选**后随下一条消息一起引用，草稿保持原样；**点击名称**则按你设置的方式替换、追加或直接发送。预设可以编辑、搜索和拖动排序，内置的划词、链接、正文也能按自己的习惯修改。

### 换一页材料，继续同一段对话

先让 AI 看一篇评测，再引用产品文档核对说法；先读一篇教程，再带入另一页的示例代码。点击预设菜单顶部的来源标题，就能搜索所有窗口里的标签页，切换引用来源。

**切换材料时，当前 AI 对话、草稿和已有附件都会保留**，也不会跳转到来源标签页。下一次引用使用新来源，已经追加到草稿的内容保留当时的快照。

每个标签页有自己的侧栏和临时引用选择，方便分别处理不同的阅读任务。

## 按你的习惯使用

| 想调整的地方 | 可以怎么做 |
| --- | --- |
| 打开侧栏的方式 | 使用工具栏图标、网页右键、快捷键或悬浮球；悬浮球可拖动贴边，再点一次关闭侧栏 |
| 哪些网页显示悬浮球 | 设置网站黑名单／白名单，也可仅本次隐藏、仅该网站隐藏或全局关闭 |
| 自定义 AI 网站 | 填写网站地址；自动识别控件不成功时，可点选发送按钮或配置 CSS 选择器 |
| 引用来源列表 | 按标题或网址搜索，也可隐藏不支持引用的浏览器内部页和 AI 网站页 |
| 扩展字体 | 选择常用字体或本机字体，预览后应用到设置、预设和引用控件 |
| 保存自己的配置 | 导出、导入网站、预设、附件规则、字体和入口等设置；导入前可预览变更 |

网站、引用、外观和入口的设置集中在侧栏顶部的 **AI 网站设置** 中；预设在原站输入框旁管理。具体步骤见 [使用指南](docs/usage.md)。

## 安装

需要支持原生侧栏的 Chromium 浏览器，例如 Chrome、Edge 或 Tabbit，最低要求 **Chromium 145**，并且能够访问你选择的 AI 网站。

### 下载扩展包

1. 在 [Releases](https://github.com/ChinaYong/Sider/releases) 下载 **`Sider-v*.zip`** 并解压。请选择扩展附件；GitHub 自动提供的 **Source code** 是源码归档。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启 **开发者模式**。
3. 点击 **加载已解压的扩展**，选择解压后包含 `manifest.json` 的目录。

请保留这个目录，浏览器会持续从中读取扩展。更新时，将新版解压到原加载目录，在扩展管理页点击 **重新加载**，然后关闭旧侧栏并重开。

<details>
<summary>从源码构建</summary>

准备好 Node.js、npm 和 Git，在终端执行：

```sh
git clone https://github.com/ChinaYong/Sider.git
cd Sider
npm ci
npm run build
```

然后按上面的步骤加载项目中的 **`dist/`** 目录。每次更新源码后重新构建，再到扩展管理页重新加载。`npm run build` 生成可加载目录，不生成 ZIP。

</details>

## 第一次使用

1. **打开侧栏**：在要阅读的网页点击 Sider 工具栏图标。默认使用 ChatGPT；可在顶部 **AI 网站设置 → AI 网站** 中切换，按提示授权并登录。
2. **选好材料**：在原站输入框旁打开 **预设**，勾选需要的划词、网页链接或网页正文。首次使用默认勾选“划词”，在来源网页选中一段文字即可引用。
3. **写下问题，照常发送**：使用原站输入框和发送方式。Sider 会在发送前准备所选材料，普通勾选在发送成功后取消；“总是选中”的划词继续保留。

勾选“网页正文”后，可以直接问：

> 请用三句话概括这篇文章，再列出作者的主要论据。

**材料由你选择，发送前再组合。** 正文在发送前更新，主动追加的内容保留追加时的快照。采集或必要附件准备失败时，会保留草稿并提示处理，不会继续发送缺少材料的问题。

常用快捷键：`Ctrl+Shift+Y` 打开侧栏，`Alt+Shift+Q` 引用当前网页划词。可在浏览器的扩展快捷键设置中修改。

## 数据与访问范围

网页材料在浏览器内采集，选中的引用会随你发送的问题或附件交给当前 AI 网站。网站、预设等设置保存在浏览器本地，划词和正文快照等临时材料保存在浏览器会话中。配置备份不包含原站登录、聊天记录、草稿或网页材料。

扩展按需请求网页访问权限；列出标签页标题和网址用于选择引用来源，读取正文仍需对应网页的访问权。为让 AI 网站在侧栏加载，扩展会对侧栏中已登记 AI 网站的子框架响应调整 CSP 和 X-Frame-Options 嵌入限制。

正文采集只覆盖**已加载的网页主要内容**，不包含未加载段落、其他 iframe、图片或 Canvas 中的文字。浏览器内部页和已登记的 AI 网站页面不能作为引用来源。

## 遇到问题

| 情况 | 可以先这样处理 |
| --- | --- |
| AI 网站无法加载或登录 | 用右上角 `↗` 在普通标签页完成登录，再用 `↻` 重载侧栏 |
| 划词或正文没有出现 | 在来源网页点击一次工具栏图标，或按提示授权；确认需要的内容已经加载 |
| 提示“网页引用未就绪” | 等原站输入框加载完成；仍未恢复时，重载侧栏或检查网站控件配置 |
| 附件上传失败 | 按提示检查原站附件区，在预设标签中重试或移除该项；也可调整为“始终文本” |

网站能否嵌入、登录或上传，取决于原站页面、网络和账号状态。自定义网站也需要满足这些条件。更多操作见 [使用指南](docs/usage.md)，测试覆盖与实际网站验证范围见 [验证记录](docs/validation.md)。

## 开发与贡献

项目使用 **Manifest V3、原生 JavaScript 和 esbuild**，正文提取基于 **Readability + Turndown**。网页采集、预设与变量展开共用一套流程，各网站适配层负责连接原站输入框、附件和发送控件。

```sh
npm ci                  # 安装锁定版本的依赖
npm run build           # 构建 dist/
npm test                # 运行单元测试
npm run test:browser     # 构建并运行隔离浏览器回归
npm run check           # 单元测试与构建
npm run dev             # 启动安装提示和示例文章页面
```

完整侧栏需要在浏览器中加载扩展；`npm run dev` 提供辅助调试页面。隔离浏览器测试的环境准备见 [浏览器测试说明](docs/browser-tests.md)，版本管理与 GitHub Actions 自动打包见 [发布说明](docs/releasing.md)。`dist/` 和扩展 ZIP 均为生成产物，不随源码提交。
