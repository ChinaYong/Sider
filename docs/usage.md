## 第一次使用

1. 打开要阅读的普通网页，用扩展工具栏图标、网页悬浮球或 `Ctrl+Shift+Y` 打开 Sider 侧栏。
2. 首次使用时，通过侧栏顶部的 **在标签页打开 AI 网站**（`↗`）在同一浏览器完成登录，再回到侧栏点击 **重新加载 AI 网站**（`↻`）。更换网站见 [选择与配置 AI 网站](#选择与配置-ai-网站)。
3. 在原站输入框旁点击 **预设**，核对顶部的 **引用来源**。需要解释某段话时，先在来源网页选中文字，再确认“划词”已选中；需要总结文章时，勾选“网页正文”。未授权时，按提示允许访问该网页。
4. 在原站输入框写下问题并发送。勾选的材料会在发送前准备好，再交给原站发送；输入框旁的预设标签可用于查看内容或取消引用。

例如，勾选“网页正文”后输入“用三点概括这篇文章”，即可把正文带入提问。也可以创建带有 `{{content}}` 的总结预设，以后点击名称直接填入或发送。

## 设置入口与保存方式

点击侧栏顶部的 **AI 网站设置** 按钮，打开包含四个分类的设置窗口。按钮名称可通过鼠标悬停查看。

| 分类 | 可调整的内容 | 保存方式 |
| --- | --- | --- |
| AI 网站 | 默认网站、网站专属设置、自定义网站与控件 | 点击 **保存更改**；网站与 Gemini 偏好在下次加载时应用 |
| 引用 | 是否隐藏不可用的引用标签页 | 点击 **保存更改**，更新所有侧栏的来源列表 |
| 外观 | 扩展字体与预览 | 选择后自动保存；自定义字体需点击 **应用字体** |
| 入口 | 悬浮球、显示名单、网页访问权限与快捷键入口 | 悬浮球偏好即时保存；权限与快捷键按浏览器提示操作 |

分类之间可直接切换，未完成的编辑和各页滚动位置会保留；分类页签也支持方向键与 Home / End。外观、入口页没有待保存的网站或引用更改时，底部显示 **完成**；有待保存内容时仍显示 **保存更改**。

关闭设置或按 Esc 时，若有未保存的更改，会显示 **继续编辑** 和 **放弃并关闭**。已经即时保存的外观与入口偏好不会因此撤销。配置备份入口位于设置窗口底部的 **配置导入／导出**。

## 预设：勾选与点击

打开原站输入框旁的 **预设**，上方是引用来源，下方是可搜索的 **消息预设** 列表与已选数量。每行包含引用勾选、预设名称和点击行为提示，例如 **追加到输入框** 或 **直接发送 ↗**。

勾选表示下一条消息要引用哪些材料；点击名称则立即按该预设的行为执行。同一位置的内容按列表顺序组合。

| 操作 | 结果 |
| --- | --- |
| 普通勾选“发送时引用” | 草稿保持原样，下一次发送时带上该项 |
| 点击名称：替换 | 用预设替换草稿文字，保留用户自行上传的文件；不发送 |
| 点击名称：追加 | 将展开内容放在问题前或后，保留现有草稿；不发送 |
| 点击名称：直接发送 | 将预设与已有草稿、其他勾选项一起准备，完成后发送一次 |

发送成功后，本侧栏的普通勾选自动取消；划词的 **总是选中** 状态保留。准备失败时勾选保留，便于重试。无划词时，依赖划词的勾选项显示“等待划词”并跳过，普通问题仍可发送；主动点击该预设时会要求补齐变量。

追加使用当时的变量快照。重复追加同一预设会更新仍完整匹配的系统文字块；你已经编辑的文字会保留。替换会先校验、准备新材料，失败时保留原草稿；原站附件清理失败时按提示核对后再试。

### 划词的三种状态

在“划词”一行反复点击勾选框，依次切换 **未选中 → 选中 → 总是选中 → 未选中**；聚焦勾选框后按空格也可切换。

| 状态 | 发送时的行为 | 发送成功后 |
| --- | --- | --- |
| 未选中 | 不自动附加划词 | 保持未选中 |
| 选中 | 有划词时随下一条消息附加 | 自动取消勾选 |
| 总是选中（`∞`） | 有划词时持续随消息附加，无划词时等待并跳过 | 保持选中 |

**总是选中** 仅用于内置划词预设，保存在本地并对所有网页与侧栏生效，重新打开后仍保留。要关闭，可继续点击到“未选中”，或取消输入框旁的划词标签；恢复划词预设默认值也会关闭它。

编辑页中的 **默认勾选，随消息引用** 用于新来源页的初始选择，普通勾选发送后仍会取消。若希望连续提问都引用划词，请在列表中使用 **总是选中**。

### 新建与管理预设

1. 在预设列表底部点击 **新增预设**；修改已有预设时，先点击 **管理**，再点击对应行的 **编辑**。
2. 在 **预设内容** 中填写名称和正文，可混合固定指令与变量。展开 **查看全部变量** 可查阅用法并复制变量。
3. 在 **使用方式** 中设置 **插入位置**（问题前／问题后）、**默认勾选，随消息引用** 和 **点击名称时**（替换／追加／直接发送）。
4. 按需展开 **高级：发送方式与附件**，调整发送方式、阈值和附件说明。最后点击 **保存预设** 即可使用，无需再到侧栏设置保存。

新建预设默认为“追加”“问题后”“始终文本”，默认不勾选。内置“划词”“网页链接”“网页正文”可以编辑和 **恢复默认**；自建预设可以在管理模式中删除。

管理模式中拖动 `⠿` 手柄调整顺序，点击 **完成管理** 返回日常列表。搜索只按预设名称筛选；搜索时暂停拖动排序，清空搜索即可恢复。

## 切换引用来源

1. 在 **预设 → 引用来源** 点击当前来源的标题。
2. 按标题或网址搜索所有可访问窗口中的标签页，选择要引用的网页。
3. 之后的预设操作使用该页的标题、网址、划词与按需采集的正文。点击 **↩ 当前页** 切回所属网页。

来源列表支持上／下方向键选择、Enter 确认、Esc 收起。切换来源保留当前对话、草稿、已追加快照及附件，也保留本侧栏的勾选。它不会继承或修改来源标签页的勾选，也不会激活该标签页。已有追加快照保持原内容，新操作才使用新来源。

成功发送后取消普通勾选，保留划词的“总是选中”状态和引用来源。手动选择的来源在本次浏览器会话内保留；来源页关闭时提示重新选择。未授权来源可点击 **允许来源网站** 授予网页访问权，浏览器内部页不支持引用。

在 ChatGPT、Gemini、Claude 等 AI 网站标签页中，也可先划词，再用工具栏图标、右键菜单或快捷键手动打开 Sider，引用该标签页的内容。关闭自动划词入口或将网站加入悬浮球黑名单，不会禁止手动引用。当前 AI 标签页会保留在自己的来源列表中，切到其他来源后也能切回当前页；侧栏内嵌的 AI 会话不作为来源。

在 **设置 → 引用** 中可开启 **隐藏不可用的引用标签页**，再点击 **保存更改**。所有侧栏的引用来源列表会隐藏浏览器内部页和其他 AI 网站页；手动打开侧栏的当前 AI 标签页仍可选择，未授权网页也可选择并授权。默认关闭，关闭后重新显示不可用条目及原因。此偏好会随配置导出、导入。

## 变量与正文快照

预设可将固定指令与 `{{变量}}` 组合。例如，创建一条“解释划词”预设：

```text
请解释“{{selection}}”在下面语境中的含义，并举一个例子：

{{selection.context}}

来源：{{title}}
{{url}}
```

| 变量 | 内容 |
| --- | --- |
| `{{selection}}` | 来源网页当前划词 |
| `{{selection.context}}` / `{{context}}` | 划词及附近的原文；前后各最多 2048 字符，并限制邻近节点读取量，避免长对话划词卡顿 |
| `{{title}}`、`{{url}}`、`{{url.host}}` | 网页标题、地址、主机名 |
| `{{content}}` / `{{page.content}}` | 采集的 Markdown 正文 |
| `{{page.author}}`、`{{page.publishedAt}}`、`{{page.capturedAt}}` | 正文作者、发布时间、采集时间 |
| `{{date}}`、`{{time}}`、`{{datetime}}` | 本机时区的日期、时间、日期时间 |
| `{{template.name}}` | 当前预设名称 |
| `{{filename}}` | 实际上传文件名，仅用于附件说明 |

编辑页的 **查看全部变量** 提供使用条件、例子和复制按钮。正文与其元信息按需采集，页面未提供的作者等字段会提示缺失；普通草稿中的花括号保持原样。

发送时引用使用发送前更新的正文；主动追加保留追加时快照，后续发送不会自动改写。一次操作中的预设共享正文与时间快照，网页材料中的变量样式文字不会再次展开。

点击预设标签可查看展开内容、字符数和预计发送方式。正文项提供 **查看正文快照**，可复制、下载 Markdown 或手动刷新；固定的追加快照通过重新追加更新。采集仅覆盖已加载的主要正文，图片、Canvas、其他 iframe 和未加载内容不在范围内。

## 长内容与附件

在 **预设 → 管理 → 编辑 → 高级：发送方式与附件** 设置发送方式：

| 方式 | 行为 |
| --- | --- |
| 始终文本 | 全文写入消息 |
| 超出阈值转附件 | 材料字符数严格超过阈值时生成 TXT；正文预置项默认阈值为 10,000 |
| 始终附件 | 材料生成 TXT；网站没有附件能力时停止操作 |

可以用一对 `<attachment>…</attachment>` 指定材料区域，让指令继续留在消息中：

```text
请总结下面的文章，列出三个关键观点。

<attachment>
{{content}}
</attachment>

请用中文回答，并保留重要术语。
```

未转附件时，标记去除、全文原位展开；转附件时，仅区域内容进入 UTF-8 TXT，原位置换成附件说明。没有标记时，以整条预设的展开内容作为材料。

每条预设只支持一个非空、非嵌套的附件区域；编辑器的 **设为附件区域** 可包裹所选文字。阈值只计算材料区域，各预设独立判断。附件说明可以编辑，默认使用预设名称与实际文件名；附件说明不支持正文变量。

多项附件按顺序上传，全部就绪后发送一次。上传前未检测到附件能力时，自动方式会提示并使用完整文本；已开始上传后失败则停止发送，不会改发文本。扩展只清理自己生成的文件，保留你自行上传的附件。

附件被移除或准备失败时，在预设标签中选择 **重试附件** 或 **移除该项**。若提示清理无法确认，先检查原站附件区、手动移除残留文件，再重试。单项材料与最终文本消息的上限为 100 万字符，超限会提示缩小范围。

## 选择与配置 AI 网站

打开 **设置 → AI 网站**，在 **默认网站** 卡片的下拉框选择网站，再点击 **保存更改**，按浏览器提示授予访问权限。默认网站由所有侧栏共用，新开或重新加载时应用。

保存设置后，已打开的侧栏先保留当前会话和草稿。准备切换时，点击 **AI 网站设置已更新，点击加载…** 提示或顶部的 `↻`，加载新设置。

内置 ChatGPT、Gemini、Claude。展开 **网站专属设置** 中对应的网站，可调整该站配置；默认网站下方的 **配置网站**（内置）或 **编辑网站**（自定义）也能打开当前所选网站的编辑器。

### Gemini 界面、模型与思考

在 **网站专属设置 → Gemini** 中，**界面偏好** 下的 **打开 Gemini Spark 界面** 开关用于选择 Spark；关闭时使用普通 Gemini 界面。**模型与思考** 下可选择默认模型和思考等级，修改后点击 **保存更改**。

Gemini 默认模型提供 **3.5 Flash-Lite、3.8 Flash、3.1 Pro、4 Argon**；思考等级提供 **低点（快速高效）、中等（深度适中）、高点（超级详尽）**。默认使用 Flash-Lite 和低点。旧配置的扩展思考关闭会迁移为低点，开启会迁移为高点，配置备份也支持这一迁移。

保存后，在下次加载普通 Gemini 界面时尝试应用；当前会话和草稿保留，点击更新提示或 `↻` 后应用新偏好。实际可用项取决于账号与网页版本，缺失或无法确认时停止自动设置。旧网页的标准／扩展开关分别对应低点／高点，无法表示中等时不会近似替代。

### 添加自定义网站

1. 在 **设置 → AI 网站 → 默认网站** 点击 **＋ 添加网站**，填写网站名称与 HTTP(S) 地址。
2. 点击 **完成编辑**，新网站会成为待保存的默认网站，再点击 **保存更改** 并按提示授予访问权限。
3. 点击侧栏更新提示或 `↻` 加载新网站。后续可通过 **编辑网站** 修改，或通过 **从列表移除** 删除自定义网站；这些修改也需要保存。

扩展自动识别输入框和发送控件。识别失败或存在多个匹配时，打开网站编辑器的 **高级配置**，指定 **输入框 CSS 选择器**、**发送控件 CSS 选择器** 和 **引用栏挂载位置 CSS 选择器**；挂载位置表示把引用栏放在该元素之后。**原站发送快捷键** 可选 Enter、Ctrl / ⌘ + Enter 或仅发送按钮。

内置网站可通过 **网站专属设置 → 对应网站 → 配置网站控件** 调整识别规则，名称和地址保留内置值；自定义网站对应入口为 **编辑网站与控件**。

### 点选发送按钮

如果原站已有输入框，但无法识别发送按钮：

1. 先保存并加载要配置的网站，在原站输入框写一点文字，让发送按钮出现。
2. 打开该网站的编辑器，点击 **在页面点选发送按钮**，再点击实际按钮；此次点击只记录控件。
3. 完成编辑、保存更改并重载侧栏。Esc 可取消点选。

要撤销手动配置，使用 **恢复自动识别发送按钮** 并保存。输入框识别、文件上传状态与内嵌登录取决于原站，自定义配置不能保证任意网站可用。

### 加载或引用未就绪

通过侧栏右上角 `↗` 在同一浏览器的普通标签页完成登录，再用 `↻` 重载。`⋯` 中的连接信息可用于排查问题，网站设置在加载失败时仍可用。

提示“网页引用未就绪”时，原站页面可能仍能正常聊天；引用能力需等输入框和控件连接恢复。采集、上传或连接失败时按提示处理后重新发送。真实网站与本地测试的覆盖范围见 [验证记录](validation.md)。

若显示“ChatGPT 在启动时反复重载”，Sider 已暂停连续重载的异常页面，连接信息仍保留在 `⋯` 中。可手动重试连接，或通过 `↗` 先在原站标签页使用；反馈问题时复制连接信息即可，无需反复刷新到灰屏。

## 悬浮球与快捷键

网页悬浮球点击打开侧栏，再次点击关闭；拖动会贴到左右边缘并记住位置。显示开关位于 **设置 → 入口 → 网页悬浮球**，修改即时保存。

在同页的 **显示模式** 中选择规则：**黑名单**为名单外显示，**白名单**为仅名单内显示。可一键将当前网站加入名单；手动添加时，展开下方的 **黑名单／白名单**，填写域名或粘贴网址，再点击 **加入名单**。规则按完整域名匹配，子域名单独设置；切换模式会保留两份名单。

悬浮球的 **×** 提供三个范围：

| 选择 | 效果 |
| --- | --- |
| 全局关闭 | 所有网页隐藏，可在设置中重新开启 |
| 仅本次 | 当前页面隐藏，刷新或重新打开后恢复 |
| 仅该网站 | 调整当前域名的名单规则，可在名单中恢复 |

悬浮球只在已授权的普通网页显示。可在 **入口 → 网页访问权限** 点击 **允许访问所有网页**，或在将当前网站加入白名单时按提示授予该网站权限。

也可用工具栏、网页右键中的 **打开 Sider 侧栏** 或 `Ctrl+Shift+Y` 打开侧栏；`Alt+Shift+Q` 引用当前划词。**入口 → 其他打开方式 → 自定义快捷键** 打开浏览器的扩展快捷键设置。

## 扩展字体

在 **设置 → 外观** 中选择系统默认、微软雅黑、苹方、思源黑体、思源宋体或等宽字体，选择后自动保存并立即应用到所有侧栏的设置、预设、引用控件及网页提示。

选择 **自定义字体**，填写一个本机已安装的字体名称（例如 `LXGW WenKai`），查看预览后点击 **应用字体**，也可按 Enter 保存。字体缺失时自动使用备用字体；**恢复系统默认** 可重置。AI 原站的聊天正文和输入框保留原站字体。

## 配置备份

点击设置窗口底部的 **配置导入／导出**，再点击 **导出完整配置** 下载 JSON。备份包含网站与控件、预设、划词“总是选中”、附件规则、引用列表过滤偏好、Gemini 设置、自动划词网站列表、悬浮球设置及扩展字体。当前导出版本为 3，支持导入版本 1、2 的旧备份；没有字体字段的旧备份使用系统默认字体。

导入时，通过 **选择 Sider JSON 配置文件** 选择备份，先查看变更预览，再点击 **按预览完整替换配置** 覆盖现有配置；旧网站与自建预设不会合并。权限由浏览器另外管理，使用相应网站时按需授权。

备份不包含原站登录、聊天、草稿、采集的正文、划词或浏览器快捷键。导入后的网站变更通过重载侧栏生效。
