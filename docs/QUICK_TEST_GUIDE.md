## 🐛 常见问题排查

### 样式没有更新？
1. 确认已运行 `npm run build`
2. 在扩展管理页点击"重新加载"
3. 关闭旧侧栏，重新打开
4. 清除浏览器缓存（Ctrl+Shift+Del）

### 对话框动画不流畅？
1. 检查浏览器是否开启了"减少动画"辅助功能
2. 打开浏览器控制台（F12）查看是否有 CSS 错误
3. 确认浏览器版本 ≥ Chrome 145

### 按钮样式不对？
1. 检查 `dist/styles.css` 文件大小是否约 22 KB
2. 确认 `dist/panel.html` 引用的是 `styles.css` 而非 `styles-optimized.css`
3. 查看控制台是否有"找不到样式文件"错误

### ID 选择器错误？
1. 查看控制台错误信息
2. 对比 `src/panel.html` 和 `src/panel.js` 中的 ID
3. 如果缺失某个 ID，从 `src/panel-optimized.html` 中找回
