# Sider UI / UX 重整

## 目标与边界

面向在网页与 AI 之间频繁切换的日常使用：选择来源、附加引用、使用预设、调整设置。优先提升视觉精致度与动效一致性，同时减少查找和误操作，让 320–420px 侧栏也能清楚呈现当前状态。

保留原站输入框与聊天、引用来源绑定、附件事务、存储格式、网站独立折叠设置、草稿保护和减少动态效果支持。

## 诊断

- 设置使用长表单加多层折叠，字体与入口设置难定位；全局保存与立即生效混在同一页。
- 预设每一行同时排列拖动、执行、勾选、编辑、删除；窄屏时名称被操作按钮挤压。
- 预设的“勾选”和“点击执行”后果不同，缺少明确的阅读顺序；没有搜索和选中数量。
- 编辑页面返回后焦点缺少稳定归属，错误信息与发生位置相隔较远。

## 方向比较

1. **分类工作区（采用）**：设置以 AI 网站 / 引用 / 外观 / 入口四个页签定位；预设保留常用操作，管理模式单独呈现排序、编辑和删除。优点是定位直接、列表安静，适合长期使用。
2. **折叠清单**：沿用长表单，增加目录和卡片摘要。改动较小，但仍然依赖滚动定位，随着功能增加会继续变长。

界面采用中性底色、单一靛蓝强调、行分隔与少量状态色。标题、导航和底部操作固定；正文独立滚动。立即保存的外观与入口设置明确标注，不冒充需要全局保存。

## 设计细节

- 外层工作区、输入控件、选中区域使用不同明度；靛蓝只强调活动入口和主要动作，避免所有卡片同时争夺注意力。
- 使用同一组浅色／深色语义色，设置与 Shadow DOM 引用菜单保持一致。16 组主要文字／背景配色检查最低为 5.16:1；不等同于完整无障碍审计。
- 设置内容切换为 160ms 轻微位移与淡入，沿用现有弹层、标签、排序动效机制；减少动态效果时关闭过渡。
- 每页独立保留滚动位置，编辑器保留 DOM；关闭待保存的设置提供就地“继续编辑／放弃并关闭”。
- 字体与入口即时保存，未改动其他设置时底部显示“完成”；有 AI 网站／引用草稿时继续提供保存入口。
- 搜索使用现有预设名称，不触发采集、发送或配置写入；搜索期间禁用排序，避免对隐藏项做含糊的位置调整。
